# 📘 Valid Perfect Square

## 💡 Concept

A number is considered a **perfect square** if it can be written as the product of an integer multiplied by itself.

👉 In mathematical form:

[
n = k \times k
]

Where `k` is an integer.

---

## 🔍 Examples

### Example 1

```id="a1xk29"
Input: 16
Output: true
```

Explanation:
`4 × 4 = 16`, so it is a perfect square.

---

### Example 2

```id="z9qpl2"
Input: 14
Output: false
```

Explanation:
No integer `k` exists such that `k × k = 14`.

---

## ⚙️ Constraints

* `1 <= num <= 2^31 - 1`

---

## 🚫 Important Note

* You **must not use built-in functions** like `sqrt`
* The solution should rely on **pure logic or math techniques**

---

## 📚 Summary

* A perfect square is the result of an integer multiplied by itself
* The task is to determine whether such an integer exists
